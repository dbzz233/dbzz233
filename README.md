## 我做过的东西

### 贪吃蛇（网页版）

一个能直接打开玩的浏览器小游戏。

- 在线玩：https://dbzz233.github.io/snake-game/
- 源码：https://github.com/dbzz233/snake-game

用的是原生 HTML + CSS + JavaScript，没有借助任何框架和现成的库——不是因为这样更好，而是因为我需要把每一行都自己写一遍才能记住。

实现的功能：方向键和 WASD 控制方向、食物随机出现且不会压在蛇身上、吃到食物身体长一格并加 10 分、撞到墙或咬到自己就结束。

做这个的过程中，有几个地方让我印象很深：

- 蛇"移动"的实现其实是**头进尾出**，所以吃到食物时只要"少删一节"，蛇就自然变长了；
- 快速连按方向键时，如果按一下就立刻改方向，蛇会掉头撞死自己——最后我用"先把方向排队、走到下一格才切换"的办法解决；
- 判断"咬到自己"时，**贴在尾巴那一格不算撞**，因为那一步尾巴刚好会挪开。这个细节我一开始漏了。

如实说明：最高分记录还没实现，触屏操作也没有。这两项在我的待做清单上。

### 文件整理工具（Python）

给一个文件夹路径，它把里面的文件按后缀分到同名文件夹里——`photo.jpg` 进 `jpg/`，`note.txt` 进 `txt/`。

- 源码：https://github.com/dbzz233/file-organizer

这个脚本教给我的，反而不是技术本身。因为它是**移动真实文件**、动的是不可撤销的操作，所以我做了几件事：先打印一份"打算怎么移动"的预演清单，确认了才动手；遇到重名文件自动加编号，绝不覆盖；遇到子文件夹就跳过。

**这类操作要先给自己留退路**——这是我写它时最大的收获。
